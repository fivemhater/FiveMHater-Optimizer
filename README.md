# FiveMHater Optimizer

Windows 10/11 için FiveM / GTA V odaklı performans optimizasyon aracı (C# .NET 8 WPF). Tam geri alma (Restore) destekli.

İndirme: [Releases](../../releases/latest)

## v2.2.0
Gizlilik ayarları, uyku/disk/hazırda bekletme, INetCache + SSD TRIM, ek Ultra servis/görevleri ve opsiyonel hazır uygulama kaldırma (varsayılan kapalı).

## v2.1.0
Yeni **Ultra / Full+Full** profili: başlangıç uygulamaları, derin servis/görev azaltma, Widgets/Copilot/Teams kapatma. Tamamı Tam Geri Al ile geri alınabilir. İşlem sayısını yeniden başlattıktan 2-3 dk sonra ölçün.
